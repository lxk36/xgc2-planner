# xgc2_cerlab_tracking_controller

XGC2-packaged version of Zhefan Xu's CERLAB `tracking_controller`, renamed into
the XGC2 ROS namespace.

This package provides the `Target` message, controller library, and
`tracking_controller_node` launch entrypoint.

Launch example:

```bash
roslaunch xgc2_cerlab_tracking_controller tracking_controller.launch
```
